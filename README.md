# 2С — Сучасна веб-система обліку та ERP (Версія 1.0.0)

**2С (v1.0.0)** — базова виробнича версія сучасної української веб-системи управлінського, торговельно-складського, CRM та регламентованого бухгалтерського обліку (альтернатива 1С / BAS Малий бізнес), готова до розгортання та встановлення клієнтам.

Стек: **TypeScript · React 19 · Vite · Tailwind CSS · Fastify · Drizzle ORM · PostgreSQL / PGlite**.

---

## Основні можливості (v1.0.0 — Базова версія)

### 1. Мульти-ФОП / ТОВ та структура підрозділів
- Необмежена кількість організацій (**ТОВ** та **ФОП** на різних системах оподаткування: Загальна з ПДВ / без ПДВ, ЄП 2 група, ЄП 3 група 5% або 3%+ПДВ) у єдиній базі з миттєвим перемиканням.
- **Підрозділи та філії** (`departments`): швидкий перемикач у шапці й мобільному меню, прив’язка працівників (користувачів і штату), складів, кас, документів і CRM-лідів до підрозділів.
- Зріз KPI дашборду, журналу документів, пошуку й CRM суто по активному підрозділу або зведений перегляд по всіх підрозділах.

### 2. Користувачі, Групи доступу та індивідуальні права
- Авторизація за **логіном і паролем** (`scrypt` + сесії `auth_sessions`, без прив’язки до сторонніх сервісів).
- **5 вбудованих груп доступу** + створення необмеженої кількості власних груп:
  - Адміністратори (повний доступ)
  - Менеджери з продажу
  - Менеджери із закупівель
  - Бухгалтери
  - Комірники та виробництво
- **16 гранулярних галочок прав** (розділи + операційні дії) для кастомного налаштування кожного співробітника поверх групи.
- **Сувора ізоляція видимості («кому який доступ відкритий — той і бачить стільки в програмі»):**
  - Обмеження по ФОП/ТОВ, по підрозділах (`Усі` / `Тільки свій підрозділ` / `Обрані галочками`) і по правах модулів перевіряється одночасно на сервері API (`HTTP 403`) та в інтерфейсі.

### 3. Повний контур обліку (BAS Малий бізнес)
- **CRM-воронка:** ліди, етапи угоди, задачі менеджерам, історія дзвінків, конвертація ліда у замовлення покупця в 1 клік.
- **Швидкі замовлення та торгівля:** миттєвий пошук і створення покупця/постачальника прямо з поля, додавання нового товару з категорією на льоту, резервування залишків, історія та зв’язки документів (**«Створити на підставі»**).
- **Склад і виробництво:** партійний облік **FIFO**, місячні підсумки, переміщення, інвентаризація, комплектація / виробництво за специфікаціями **BOM**.
- **Кадри та зарплата:** штатний розпис із віднесенням до підрозділів, відомості нарахування ЗП (ПДФО 18%, ВЗ 5%, ЄСВ 22%).
- **Основні засоби (рах. 10/13)** з щомісячною амортизацією та **мультивалютний облік (USD/EUR)** з автозавантаженням курсів **НБУ** і курсовими різницями.
- **Бухгалтерія №291 і звітність ДПС:** подвійний запис Дт/Кт із Субконто, ОСВ, **SAF-T UA v2.0 XML**, Податкові накладні (**J1201015 XML**), **Баланс (Ф1)**, **Звіт про фінрезультати (Ф2)**, **Декларація з ПДВ**, **Декларація ЄП**, **Об’єднаний звіт ЄСВ/4ДФ**.
- **Інтеграції:** BAS OData, Monobank API, Приват24 для бізнесу, Checkbox ПРРО, CSV-імпорт.

### 4. Сучасний інтерфейс, мобільна версія та публічні посилання
- Світлий Bento-дизайн із фірмовим логотипом **2С**, розумним глобальним пошуком **`⌘K`**, авто-схованим доком швидких дій на десктопі та адаптивною **мобільною версією**.
- **Відкриті онлайн-посилання на документи (`/share/:token`):** будь-яке замовлення, рахунок, накладну чи касовий ордер можна відправити клієнту в Telegram / Viber / WhatsApp без входу в систему (із копіюванням IBAN та друком PDF).

## Встановлення для нового клієнта

### Вимоги
- **Node.js 20+** (перевірено на Node 22 / 26)
- **PostgreSQL 15+** (рекомендовано для production) або вбудована **PGlite** для швидкого старту без окремої БД.

### Кроки розгортання
```bash
# 1. Клонування базової версії v1.0.0
git clone <URL_ВАШОГО_РЕПОЗИТОРІЮ> 2c-client
cd 2c-client

# 2. Встановлення залежностей
npm install

# 3. Налаштування змінних середовища
cp .env.example .env
# Відредагуйте .env: задайте DATABASE_URL (для PostgreSQL) та надійний ADMIN_PASSWORD

# 4. Перевірка збірки та автотестів ядра (18/18)
npm run build
npm test

# 5. Запуск у режимі розробки / тестування
npm run dev:api   # API сервер: http://127.0.0.1:4000
npm run dev:web   # Web UI:     http://127.0.0.1:5173
```

### Запуск у production
```bash
npm run build
npm --workspace @bas-alt/api run start
# Зібрана статика фронтенду знаходиться у apps/web/dist/ (роздається через Nginx/Caddy із проксі /api -> :4000)
```

| `sales` | `sales123` | Менеджери з продажу | Тільки «Відділ продажів» |
